The AIV-1 API

AIV-1 is the AI system behind AIV X. Its API works with the same format many developers already use, so most existing code needs only a new address and key. It includes AIV-1's built-in web search for current questions, fact checking, photo understanding, and AIV Code for programming.

Questions

How do I get an API key?

Contact AI Verse at team@aiverse.it.com.

Does it work with existing OpenAI code?

Usually yes. Change the base address, the key, and the model name.

Which model should I use?

aiv-1 for most things, aiv-1-code for programming, aiv-1-think for harder reasoning, and aiv-1-fast for quick replies.

Is there a rate limit?

Each key has a daily limit. Contact AI Verse for higher limits.
